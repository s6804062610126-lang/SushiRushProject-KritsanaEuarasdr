# Sushi Rush

เกมทำซูชิ เขียนด้วย Java (Swing)

## วิธีเล่นบนเครื่องอื่น

1. ติดตั้ง Java JDK (เวอร์ชัน 17 ขึ้นไป) — https://adoptium.net
2. ดาวน์โหลดโปรเจกต์: กดปุ่มเขียว **Code → Download ZIP** บนหน้า GitHub แล้วแตกไฟล์
   (หรือ `git clone <ลิงก์ repo>`)
3. รันเกม
   - Windows: ดับเบิลคลิก `run.bat`
   - Mac / Linux: `sh run.sh`
